# Brand logo picker

Preview-only change requested by the owner. Native brand values and model dependency remain unchanged. Brands are searched by name/aliases; the existing Other/manual entry remains available. Dialog supports Escape, arrow keys and native focus trapping. Model options remain text.

Brand artwork is rendered on white tiles without recoloring. Images are compiled into one local lossless WebP sprite (2x tiles), avoiding per-brand third-party requests. Logos identify the brands; they do not indicate affiliation or verification.

Sources and per-brand provenance: `brand-logo-sources.json`.
- https://github.com/filippofilip95/car-logos-dataset (MIT-labelled dataset; trademark rights remain with brand owners)
- https://github.com/javimogan/vehicle-logos-dataset
- https://github.com/vehiclespecs/brand-logos (license included below)
- https://carbrandlogos.com/ (additional brand identification artwork)

Missing artwork uses initials; no substitute brand logo is invented. This collection contains both heritage and current artwork and should not be described as all brands' latest official logo revisions.
