# Vehicle name catalogue

Expanded on 2026-09-30 from 30 brands to 208 brand entries and 2,535
brand/model pairs. Model families and some market names are included, not every
engine, trim or generation. This is a broad catalogue, not an exhaustive global
register. Unknown names remain editable in listing creation, editing and search.

Base: https://github.com/serhatkildaci/global-car-models (data/models.json, MIT).
License retained in assets/car-data-license.txt. SosAvto merged its original
catalogue and additions for Chinese, regional and historic vehicles. Original
stored spellings, including LiXiang (Lixiang) and Land Rover / Range Rover,
are retained to preserve existing filters. Li Auto/Li and VAZ/Jiguli input
aliases resolve to the existing spelling and Lada respectively.

Selected manufacturer sources checked:
- https://www.liauto.com/
- https://aito.auto/model/
- https://www.denza.com/cn/denza-voice.html
- https://www.denza.com/my/brand

Earliest accepted listing year is now 1886. Names are plain text, escaped on
render, and still constrained by server field lengths. No paid catalogue API.
