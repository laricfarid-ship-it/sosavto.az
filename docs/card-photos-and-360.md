# Card photos and future 360 capture

Cards now expose up to eight ordered photo URLs through the shared listing projection. Multiple images use a native horizontal scroll-snap track, previous/next buttons, keyboard arrows/Home/End, current-photo counter and lazy images. Each photo remains a listing link; horizontal pointer gestures suppress accidental click navigation. Favorites and comparison controls remain separate. Single-image, missing-image and registration plate cards retain their existing presentation. Hover-capable fine pointers get a small lift/zoom; reduced-motion users get no animation. No autoplay or forced touch scrolling lock.

The detail page already supported photo swipes; this release adds card-level browsing. Sellers upload two to eight ordinary photos (JPEG/PNG/WebP, each <=3 MB); the first is the cover. Front-three-quarter, rear-three-quarter, both sides, interior, dashboard and visible defects provide useful ordinary gallery coverage.

360 support is now implemented separately; see vehicle-360.md for the active 24–36 frame uploader, moderation, viewer and capture guidance. The ordinary eight-image gallery still does not automatically become a spin.
